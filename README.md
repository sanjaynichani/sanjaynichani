# Sanjay Nichani

I work on technical implementation and customer solutions: turning workflows and integration problems into systems people can use. These projects show how I approach product scope, data handling, debugging, and verification.

## Selected work

### [Up to Speed](https://github.com/sanjaynichani/up-to-speed)

A local-first Mac app for capturing context and turning it into a brief. The repository is the Electron, TypeScript, and React source, with tests and screenshots of a fictional integration handoff. There is no installer.

### [Attio to Notion: companies and people](https://github.com/sanjaynichani/attio-notion-companies-people-example)

An offline example based on a previously deployed sync. It covers record mapping, pagination, and relation handling with invented data. It does not connect to accounts, and it does not verify that the original worker still runs.
